# Canary Dashboard

Index of the vault's decisions, specs and runbooks. Tables are generated by the Dataview plugin.

## Decisions

```dataview
TABLE file.mtime AS "Last modified"
FROM "decisions"
SORT file.name ASC
```

## Specs

```dataview
TABLE file.mtime AS "Last modified"
FROM "specs"
SORT file.name ASC
```

## Runbooks

```dataview
TABLE file.mtime AS "Last modified"
FROM "runbooks"
SORT file.name ASC
```
